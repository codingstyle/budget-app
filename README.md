# Budget

## What is Budget?

Budget is a macOS native app written in Swift for viewing and tracking bank operations (debits, credits, transfers).

## Features

- Mutiple tags on operations
- Brands display supports
- Filtering system to automatically tag and assign brands to operations based on text
- Automatic credit card detection

## Banks

Currently, only **BNP Paribas** is supported using the Excel file export available from their web interface.

## Contributions

This app is open to new contributions! Feel free to submit PRs.

## AI

Code was entirely written using Cursor. It contains rules to guide LLM into writing working code.
